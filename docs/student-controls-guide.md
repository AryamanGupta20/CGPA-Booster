# Student website controls

## Find what you need
Use **Search** in the bottom toolbar. Search for course, exam, placement, résumé, money or confidence. Signing in is required to use account tools. Exam preparation is inside College Courses; choose your course and open its exam section.

## Appearance and navigation
- Use **Dark mode** or **Light mode** to switch appearance on this browser.
- On a small screen, use **Menu** on the welcome and account pages.
- **Top** appears after scrolling down.
- Keyboard users can use **Skip to content**.
- Reduced-motion preferences limit the utility animations.

## Account help
Use **Help** for contact details and account recovery. Save the recovery code shown after signup in a safe place. Do not include it, passwords or private keys in support messages.

## Before leaving a page
Wait for a saved or successful result. A loading label means a request is still running. If you go offline, keep unsaved text and retry after reconnecting. Cancelling a deletion confirmation keeps the selected item.

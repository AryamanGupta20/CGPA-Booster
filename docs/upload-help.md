# Attachment help

Support requests accept up to **five files**, each no larger than **1 MB**.

| Format | Extension |
| --- | --- |
| PDF | .pdf |
| Images | .png, .jpg, .jpeg, .webp |
| UTF-8 text | .txt |
| Word document | .docx |
| Excel workbook | .xlsx |

## When an upload is rejected
1. Check the size and file count.
2. Open the original file in its normal application.
3. Export or save a fresh copy in a supported format.
4. Submit again and wait for confirmation.

Renaming a file extension does not convert its contents. Password-protected or macro-containing Office files are not supported by the container check. Older .doc and .xls formats are not accepted.

If storage is unavailable, submit the description without files or try later. Include enough detail for the administrator to understand the problem.

Files are checked for expected signatures and Office container entries. This is not an antivirus scan. Avoid uploading passwords, recovery codes or unrelated personal documents.

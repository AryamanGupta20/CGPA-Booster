# Admin content publishing checklist

## Before publishing
- Use a clear title and check the destination link.
- For course resources, use a full YouTube playlist URL.
- Check the course, subject, language or topic fields.
- Keep unfinished resources in **Draft**.
- Mark a resource **Ready** only after reviewing it.

The content API hides non-Ready items from students and signed-out visitors. Administrators can see drafts. Check the student view separately; an admin preview does not prove a resource is publicly visible.

## Placement resources
Check the original company source and application deadline. Describe eligibility accurately. Do not claim a company partnership or guaranteed placement without evidence.

## Activity records
Core course/video edits, placement edits, support-request status changes and campus settings edits write admin activity records alongside the change. These records identify actions; they do not provide a complete before-and-after copy of every edited field.

## After publishing
Open the affected student tool, check the wording and link, and verify that it works on a phone-sized screen. If a mistake appears, return the item to Draft while correcting it.
